# harlem_shaker

Self-contained revival of Moovweb's Harlem Shake bookmarklet, plus a GitHub Pages install page.

Hard rule: the mp3 is a gitignored build input. Never commit it as a file or serve it at its own URL; it ships only inlined (base64) in the built bookmarklet/page. See graph entity **harlem_shaker Architecture**.
