Harlem Shake

The 2013 bookmarklet that made any web page do the Harlem Shake. It's been dead for years. Now it isn't.

Harlem Shake Drag it to your bookmarks bar, or click it to try it here. Sound on.

How to use it

  1. Show your bookmarks bar (⌘⇧B or Ctrl+Shift+B).
  2. Drag the red button onto it.
  3. Open any page with a bit going on, and click the bookmark.

What happens

One thing starts shaking. Then the drop hits and everything joins in.

{{SIZE}}, song included.

Why it broke

Moovweb's original loaded its song and stylesheet from an S3 bucket that no longer exists. Many sites' security policies would block those loads anyway.

What changed

The stylesheet and song are inlined and the song plays through Web Audio, so it makes no network requests. Pages still have to allow inline styles, which most do.
