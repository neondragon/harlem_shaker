Harlem Shake

The 2013 bookmarklet that made any web page do the Harlem Shake. It's been dead for years. Now it isn't.

Harlem Shake Drag it to your bookmarks bar, or click it to try it here.

{{SIZE}}, song included. Turn your sound on.

How to use it

  1. Show your bookmarks bar (⌘⇧B or CtrlShiftB).
  2. Drag the red button onto it.
  3. Open any page with a bit going on, and click the bookmark.

One thing starts shaking. Then the drop hits.

Why it broke, and what changed

Moovweb's original loaded its song and stylesheet from an S3 bucket that no longer exists. Even with the bucket back, many sites' Content Security Policies would block loading them.

This version carries everything with it: the stylesheet and the song are inlined, and the song plays through the Web Audio API, so the bookmarklet makes no network requests. It still needs the page to allow inline styles, which most do. A few sites block bookmarklets outright; there's nothing to be done about those.
